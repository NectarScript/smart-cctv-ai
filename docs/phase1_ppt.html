Literature Review — Key Findings

02

Person Detection

  • YOLOv8 family: nano (3.2M params) to xlarge (68.2M params).
  • YOLOv8n: 37.3 mAP on COCO, 25-40 FPS on CPU.
  • Best speed/accuracy trade-off for real-time surveillance.

Multi-Object Tracking

  • ByteTrack (ECCV 2022): uses low-confidence detections as secondary matches.
  • 2-3x fewer ID switches than SORT on MOT17.
  • No Re-ID features needed — pure motion-based.

Pose Estimation

  • MediaPipe BlazePose: 33 keypoints, real-time on CPU.
  • ~92% PCKh on MPII dataset (full complexity).
  • Optimized for mobile/edge — no GPU required.

Behaviour Classification

  • ST-GCN (~82% NTU-RGB+D) — graph-based, computationally heavy.
  • LSTM on keypoints (~75%) — simpler, real-time feasible.
  • Rule-based: deployed in commercial systems (BriefCam, Avigilon). Understudied in literature.

M1 — Multi-Camera Ingestion

04

What We Built

  • CameraSource: threaded capture for webcam, RTSP, video files.
  • CameraManager: manages N cameras, round-robin frame retrieval.
  • Preprocessor: crop, letterbox, color conversion.
  • Drop-oldest buffering: prioritizes recency over completeness.

Design Decisions

  • Thread per camera (not asyncio) — OpenCV releases GIL during read().
  • Bounded queue (maxsize=64) — prevents memory blowup.
  • CAP_PROP_BUFFERSIZE=1 — minimizes internal OpenCV latency.
  • Daemon threads — clean shutdown on pipeline stop.

M2 — Detection & Tracking

05

Detection Pipeline

Frame → YOLOv8n → Person Filter → sv.Detections
sv.Detections → ByteTrack → Tracked IDs → TrackStore

Key Metrics

  • YOLOv8n: 3.2M params, ~37.3 mAP50-95 (COCO).
  • ByteTrack: < 2ms association per frame.
  • TrackStore: 300-point history per track, velocity/displacement computation.
  • Warmup pass eliminates first-inference latency.

Pose Architecture

  • MediaPipe Pose: 33 keypoints per person crop.
  • Per-crop estimation (not per-frame) — better quality.
  • Sliding window buffer (30 frames) per track ID.
  • Classifier facade: rules now, LSTM/GRU later.

Current Limitations

  • CPU-only (no GPU acceleration).
  • No cross-camera track association.
  • No ML-based classifier (rule-based only).
  • Unattended object detection not feasible.
  • Pose quality degrades on top-down camera angles.
  • No context awareness (zone-based rules).
